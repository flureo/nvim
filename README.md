## Just a simple neovim configuration.

Don't expect this repo to be maintained of a long time. This is a small project for me to store my neovim configs.

### Installation
```bash
sudo pacman -S neovim git tree-sitter-cli
cd ~/.config/
rm -rf nvim/
git clone https://github.com/flureo/nvim.git
```

### Plugins

Here are all the plugins I used!

- [Lazy](https://github.com/folke/lazy.nvim) - Great plugin manager!
- [LSP Config](https://github.com/neovim/nvim-lspconfig) - LSP client.
- [Mason](https://github.com/mason-org/mason.nvim) - LPS manager.
- [Blink](https://github.com/saghen/blink.cmp) - Syntax completion.
- [Treesitter](https://github.com/nvim-treesitter/nvim-treesitter) - Syntax highlighting.
- [Telescope](https://github.com/nvim-telescope/telescope.nvim) - Fuzzy finder.
- [Lualine](https://github.com/nvim-lualine/lualine.nvim) - Status bar.
- [Vimcord](https://github.com/vyfor/cord.nvim) - Discord rich presence.
- [Tokyonight](https://github.com/folke/tokyonight.nvim) - Tokyonight theme.
